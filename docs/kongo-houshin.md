## いちばん大事な考え(ノブさんの言葉)

- 3D は粗い形でいい。**形・色・並び(デザインとバランス)**で見せる。重さを測って、1つずつ良くする。
- 友だちと気軽に集まれる店。

→ 直すときの物差しは「**大将が楽に回せるか**」「**会話が読みやすいか**」「**年配の人でも押せるか・読めるか**」の3つ。

## 直し方(大事な順)

### A. 小さく直せるもの(それぞれ 数十分〜半日)

1. **字と押す所を大きくする**(お客さん「字と押しやすさ 42点」)
   - 名札: 字 11px → 14px。押せる範囲は 44px 角(見えない余白を足す)。名札は話しかける・こそっと話すの入口なので、いちばん大事。
   - 右のボタンの字 10.5px → 13px。会話の字 13.5px → 15px。「？」 28px → 40px 角。お品書きの説明 11px → 13px。
   - 設定に「字を大きく」を入れる(年配の人向け)。
2. **言葉の直し**(ノブさんの OK が要る)
   - 「☰ メニュー」 → 「☰ ほか」(居酒屋で「メニュー」は品書きの意味になるため)
   - 「店主」 → 「大将の操作」(ほかの所は、すべて「大将」と呼んでいるため)
   - 「大将あり」 → 「大将がいます」
   - 👁 のボタン → 「見え方」(今は、今の見え方の名前が出ていて、押すと何になるか分からない)
   - お品書きの「「食べる」「飲む」を2回押すと空になり…」 → 「食べ終わると大将が下げます」
3. **乾杯の輪の札**: 「🍻 1人」だけでは分からない → 「乾杯の輪 1人(みんなを待っています)」。お品書きの板より下に出す。
4. **横向きでも会話を見せる**: 新しい会話 2〜3行を左下にいつも出す(今は「全部見る」を押さないと読めない)。
5. **注文の印を名札にも**: 注文した人の名札に 📋 を付ける。縦の「接客」でも、横の小さいカードでも、だれが頼んだかすぐ分かるように。
6. **こそっと話の入口**: 入力欄の横に「🤫」ボタンを置く。札は「🤫 こそっと中」と短く(小さい画面で切れていた)。3まいの案内にも入れる。

### B. 大将の画面を整理する(1〜2日。ここがいちばん点が上がる)

7. **大将の操作を3つの見出しに分ける**
   - 今は縦に約3画面・ボタン 40個。いちばん上が「閉店」、次が「会話を全部消す」で、危ない物が上にある。
   - 分け方: 「**いまの営業**」(延長・料理の出し方・お祝い) / 「**お店づくり**」(雰囲気・看板・席の数・曲) / 「**おしまい**」(閉店・全部消す)。危ない物はいちばん下。
8. **まちがい防止**
   - 確認なしで変わる物: 席の数・料理を下げる・お祝い・アイちゃんの設定を戻す。→ 押したら5秒だけ「元に戻す」が出る知らせを付ける(確認の小窓より手早い)。
   - 交代した大将(お客さん)には、閉店・全部消す・帰ってもらう・席の数を出さない。
9. **交代した大将への案内(見習いモード)**
   - 交代して最初の1回だけ、3まいの案内:「📋注文票 → 出す」「お客さんを押す」「🏮でお店の設定」。注文票ボタンを光らせる。
   - 使えるボタンを絞る。終わったら「今日の大将」の記念カード。
10. **アイちゃんのパネルを分ける**
    - 今はボタン 153個・縦に約5画面。接客中に使うのは「来る・帰る」と「ひとこと」だけ。
    - パネルはこの2つだけにして、服とくわしい設定は別の見出しに。
11. **右のボタンの場所をいつも同じに**(お客さん・大将 両方)
    - 今は画面の大きさや ☰ を開くかどうかで並びが変わり、「帰る」が押しまちがえやすい所に来る。
    - 下に4〜5個の固定の列を置く。お客さん: 話す・注文・見え方・ほか。大将: 注文票・大将の操作・アイちゃん・見え方。「帰る」は「ほか」の中へ。
12. **縦の「接客」のカメラ**: いちばん手前の人が半分切れている → 少し引いて中心をずらす。こそっとの吹き出しが別の人の頭に出る不具合も直す。

### C. 楽しさを増やす(A・B のあと)

ノブさんの考え(大将と話す・みんなで楽しむ・文字の会話)に合うものから。

- **「わたしの店」を1押しで**: 雰囲気・看板・曲・アイちゃんの服をまとめて保存して呼び出す。交代した人も自分の店にできる。
- **大将の「今日のおすすめ」黒板**: 大将が3品選ぶと、お客さんの注文画面のいちばん上に出る。大将ごとの個性が出る。
- **帰るときのうれしさ**: 大将の「またおいで!」・自動の「ごちそうさま」・次に開く日の表示。今は、スマホの決まった確認のあと、すぐ入口に戻るだけで味気ない。
- **沈黙をふせぐ**: 大将からの「今日のお題」、会話に一言の反応(LINE のように)、乾杯で振り向く(11-23 済み)。
- **常連のうれしさ**: 名前で迎える・常連の札が壁に増える・「いつもの」で前回の飲み物を頼める。
- 使い方ページに、画面の写真を入れる(年配の人には「このボタン」と写真で見せるほうが伝わる)。

### やらないこと(ノブさんの判断)

- 座ったときに、ほかのお客さんの顔を大きく見せる作り(係の1人は「いちばんの悪い所」としたが、ノブさんは「顔を見に来る店ではない、今のままがいい」。11-23)。必要なときは「おしゃべり」の見え方がある。

## 進め方の決まり

1. **1回に1つの山だけ**直す(A → B → C の順。B は 7→8→9→10→11 の順)。
2. 本番が main なので、長い直しは**別の枝**で作り、終わってから本番へ(自動の同期が、途中の版を公開してしまうため)。
3. 直したら毎回、4つの大きさ(320x568・375x667・390x844・横844x390)で撮って、**お客さん係・大将係に採点**してもらう。点が下がった所があれば戻す。
4. **重さを毎回測る**(古いスマホで止まらないように)。
5. 両方 70点を超えたら、**本物の友だちで試す**(Firebase の準備が要る。今はおためしモードで、こそっと話も本番では試せない)。
